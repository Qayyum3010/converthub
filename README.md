# ConvertHub

A free, no-signup web tool for converting documents between formats and performing
common PDF operations (merge, split, compress, compare, analyze).

## Status

Early development — not yet deployed.

## Stack

- Frontend: Next.js (client/)
- Backend: Fastify (server/)
- Conversion engines: Pandoc, LibreOffice headless, qpdf/pdf-lib, Tesseract OCR

See `project-docs/` for full planning docs (not shipped/gitignored).
